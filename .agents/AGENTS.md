# Workspace Agent Rules

## Communication Style

- **No summaries, no thinking out loud, no preamble.** Do not explain what you are about to do or narrate your reasoning.
- When finished, output only:
  1. A single line: **"Done."** (or a brief task-completion confirmation if a specific word was requested).
  2. A short **"Key highlights"** bullet list — only items the user *must* know: breaking changes, caveats, follow-up actions required, or important decisions that were made on their behalf. Omit this section entirely if there is nothing important to flag.
- Never restate what the code does. Never describe changes already visible in the diff or file. Never apologize or add pleasantries.
